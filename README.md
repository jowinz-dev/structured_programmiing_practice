* ## Category 1 - Basic Output
* **Textbook Reference:** Deitel & Deitel, *C How to Program (9th Edition)*, Chapter 2, Section 2.2 & Exercise 2.17.
* **Objective:** To master the fundamental use of the standard input/output library (`<stdio.h>`) and display structured text on the console.
* **Concepts Used:**
  * `#include <stdio.h>`: The standard header file needed for input/output operations.
  * `main()` function: The starting execution point of every C program.
  * `printf()`: The standard output function used to send character streams to the screen.
  * Escape Sequences: `\n` to move the cursor to a new line, and `\t` to neatly space text using tabs.
* **How it works:** The program executes sequentially from top to bottom inside the main function. It calls a series of `printf()` functions to print string literals, creating a clean, structured visual dashboard displaying student details on the terminal screen.
